**读法。** `[W]` 或「静态」表示在原版 Wasm、归档 JS 或 HTML 中可定位；`[C]` 或「实测」表示原件在受控浏览器输入下实际执行；“推断／待证”表示尚无足够的原版证据。调用过绘制函数不代表该内容已显示到屏幕。章节里的逻辑尺寸和实测 CSS/backing 像素有明确区分；函数 `$N` 来自 Binaryen 132，浏览器在未插桩原件中的 `wasm-function[N+358]` 对应同一函数。JS `ASM` 数字是 glue 中的 `Kb` 键。

**对照边界。** 本地 fixture 只提供可重复的协议输入。它提供的名字、房码、波次、存档或物品不是 2022 年官方服务端历史状态。Wave 现有的 Garden/Desert/Ocean 下拉框、重连提示、开发库存和本地 PvP 兼容提示是宿主附加物。使用原件 Canvas 配合本地宿主截帧时须隔离这些 DOM 元素；大厅脚本直接加载归档 HTML、JS 和 Wasm，可用来复核此差别。更早的协议定位见[原客户端取证](../client-20221030.md)；项目模拟规则和 tooltip 数据的链接由相关功能章各自列出。

本次交付的是 UI 规格和原版取证。章节覆盖已识别的界面族；已实测分支、只有静态证据的分支，以及尚无法从当前夹具触发的分支在 [08](08-parity-validation.md) 分开标记。未取得原版参照的状态不能记为通过 1:1。
