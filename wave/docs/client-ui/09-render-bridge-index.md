# 09 · 绘制桥全量索引与残余分支审计

[asm-index.json](evidence/asm-index.json) 固定原版 Wasm/JS 摘要与 Binaryen 132 WAT 摘要，保留 **153 个 `Kb` 回调的完整原 JS 函数体**、在 JS 中的起始字节偏移/长度，以及 **3381 处**键值常量引用的 Wasm 函数和 WAT 行号。每个键都有引用。它包含绘制、输入、宿主、资源和网络桥；按功能查阅 [01](01-renderer.md) 到 [07](07-world-rendering.md)。

## 如何使用索引

1. 从效果找到 `ASM` 键，读原函数体，再按 `watConstReferences` 逐个进入调用者；该字段只证明出现相同的 `i32.const`，仍需读外层控制流判断是不是实际的桥调用。
2. 当参数或状态来自间接调用，继续沿 element 表与对象 vtable 还原目标；从控件构造、更新、绘制到销毁闭环。记录控件的门控条件和最终合成目的地。
3. 为所有有条件的分支建立 [08](08-parity-validation.md) 的 case。区分路径创建、离屏缓存生成、主画布显示和 DOM 副作用；在 trace 中保留本帧没重建但仍被 `drawImage` 使用的历史缓存。

| 操作族                               | 查找键                                                                               |
| ------------------------------------ | ------------------------------------------------------------------------------------ |
| Path2D 分配与路径                    | `145535–145993`                                                                      |
| 画布创建、尺寸、检测、回收           | `146168/146438`、`148760–149810`、`150089/150170`、`153149`、`155129`                |

## 不能漏掉的五个键

现有 [glue 校验器](../../tools/reference/glue.mjs) 统计 `a.a/a.c/a.d` 的**首参数直接是常量**的调用：148 个键、3374 处。剩余五个键通过条件选择、分支返回或局部变量传入，同样参与 UI：

| 键     | 作用                    | Binaryen 132 定位           |
| ------ | ----------------------- | --------------------------- |
| 145277 | 默认指针                | `$939`，WAT 653688 / 653766 |
| 145341 | 可点击指针              | `$939`，WAT 653765          |
| 145405 | 文本指针                | `$939`，WAT 653724          |
| 148914 | OffscreenCanvas 2D 分配 | `$254`，WAT 148512          |
| 149223 | 普通离屏 Canvas 2D 分配 | `$254`，WAT 148511 / 148515 |

`$939` 先依据控件虚方法选择指针，再通过局部变量进入 import；`$254` 在 OffscreenCanvas 支持状态和对象标志下选择分配器。只搜索 `call import → i32.const` 会漏掉这两类可见行为。3381 是所有键的语法常量引用总数；它与 3374 的差不能当成运行时调用次数。

## 复建索引

需要仓库根目录开发依赖中的 TypeScript（只用于解析归档 JS），以及 `wave/node_modules` 的 Binaryen 132。脚本只读原件，写出索引；不会执行 `Kb` 中的代码。

```sh
wave/node_modules/.bin/wasm-dis wave-reference/20221030/client.wasm -o /tmp/wave-20221030.wat
node wave/docs/client-ui/tools/index-asm.mjs /tmp/wave-20221030.wat
```

输出必须复现 153 / 148 / 3374 / 3381 四个计数；WAT 的不同工具版本、格式或插桩会改变行号/摘要，不能继续复用本索引。索引覆盖的是这版 EM_ASM 桥，不代表已穷举 Emscripten/SDL 的其它 import，也不代表所有可见状态已经完成像素验收。
