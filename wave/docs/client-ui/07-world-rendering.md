## 图形提取与重用

1. 先从 [20221030 目录](../catalog-20221030.md) 固定 type/rarity/variant ID。原件 `$22` 怪物注册与 `$597` 世界绘制可闭环；`wave/tools/reference/catalog.mjs` 演示花瓣注册、构造表槽与 vtable 的读取，`wave/tools/reference/mob-tooltips.mjs` 演示怪物目录。函数表槽不等同于函数索引；以 WAT 的 element 段映射。
2. 在只读参考运行中采集每个具体的图形：Path2D 的 move/line/arc/quad/cubic/close，Canvas 路径指令、变换、RGB/alpha、描边和 clip，以及离屏源/目的 rect。内嵌 SVG path 字符串须从 data 段按使用位置取得，保持原坐标、曲线和填充规则；不要用归档图片上手描替代矢量数据。经 `ASM 153534` 实际加载的 Blob/URL 另记来源与 ready 条件。
3. 以「同一模型、各消费方独立变换」实现。用同 type 在图鉴、Tooltip、快捷栏和世界的四组样本核对：图形轮廓相同也不代表旋转、时间、姿态和 tint 相同。掉落地面卡、花瓣实例、阵亡头像及条目未解锁占位也分开取证。
4. 世界层应使用同一相机和剪裁完成后再与屏幕层合成。截屏时定格模拟/客户端时钟，或对动画帧序列逐帧配对；测试默认与最小波次/隐藏掉落/关闭震屏，检查被遮挡的对象确实未影响上层点击。

## 覆盖边界

没有将 45 个非零花瓣 ID、35 个非零怪物 ID 的所有姿态/稀有度逐一转写成新绘图器。本章给出原版查表与抓取方法；当某个图案没有原版绘制 trace、有效 wire 触发和像素差分时，不能宣称其世界版本或图标已经达到 1:1。目录中同名怪物（如 Ladybug、Centipede 和 Leech 的多个 ID）不能合并为一个世界模型。
