# 02 · 启动、主菜单、账号与小队

本页依据 `wave-reference/20221030/client.wasm`、同目录 `client.js` 和经 SHA-256 核验的归档 HTML/CSS/WOFF2。Wasm 函数名按 Binaryen 132 的 `wasm-dis` 输出记为 `$n`；`ASM n` 为 JS `Kb` 分派号；文本地址为 Wasm 线性内存地址。运行时用 Chromium 156.0.8078.47 加载未修改的 JS/Wasm，联机状态由拦截的 HTTP 发现和本地 fixture WebSocket 提供，只证明原客户端消费这些状态后的显示。底层字节见 [登录、大厅与小队](../protocol/07-lobby-and-squad.md)。

广告是独立宿主层：HTML 将第三方 CMP 配置为居中，隐私按钮文案 `Privacy settings`、位置左下；广告配置为居中 960×540，文案 `loading advertisement`。Wasm `$456` 经 ASM 148080/148302 检查并调用可选 preroll。重放拦截第三方脚本，无法由此恢复广告或 CMP 自身像素。Wave 的 `#wave-connection`、`#wave-mode-notice` 和左上场景选择框来自 `wave/web/local.js`，均不属于 2022-10-30 原界面。

## 菜单坐标、图层和输入

`$939` 是主帧回调（Wasm 表槽 366，Chromium 索引 1297），其中包含主菜单绘制。设 backing store 为 `W×H`，`$617` 先取 `f32(max(W/1920,H/1080))`：桌面夹到至少 `f32(0.7)`；移动 UA 分支不夹，手机乘 1.5，iPad/Tablet 乘 1（ASM 147419/147661，按 UA token）。`$939` 对 `W/s,H/s` 的 f32 商向上取整，得逻辑宽高 `LW,LH`。下面以 `(LW/2,LH/2)` 为中央原点，量纲为逻辑单位；用原 f32 矩阵顺序再乘 `s`。实测 1024×768 DPR1 `s=.7111111`、1280×720 DPR1 `.7`、800×600 DPR2 `1.1111112`、480×854 DPR1 `.7907407`。1280×720 标题实际落点 x=640.1499634 backing px，不是 640。

左上四枚中心为 `(32.5+55*i,32.5)`，45×45、角 4、边 3：齿轮 `#aaa/#8a8a8a`、卷轴 `#9bb56b/#7e9357`、Discord `#5865f2/#4752c4`、Reddit `#ff4500/#cf3800`。左下三枚中心依次 `(50,LH-200)`、`(50,LH-125)`、`(50,LH-50)`，60×60、边 4；灰化底/边分别 `#949494/#787878`、`#a5a5a5/#868686`、`#cdcdcd/#a6a6a6`。齿轮、卷轴及左下经济/图鉴面板的状态由相应组件独立管理。

## 重建与验收

1. 恢复原版 HTML 起始态、Ubuntu 700 的六份 WOFF2 和 Canvas 缩放，再接 `Connecting → Menu → Squad → Playing`。对照页以归档原件为基准，避开会替换提示、注入 selector 或修改 Wasm 的 `local.js`。
2. 精确同步昵称/邀请码的命中、光标、裁剪、UTF-8、退格、粘贴与输入事件。字体加载完成后比较画面；曾调用 `strokeText` 不是可见判据。
3. 保存 backing PNG 与有序 Canvas trace，逐项比较文本、样式、矩阵、路径、clip、绘制序和离队 hash。稳定态至少包括 HTML Loading、Canvas Connecting、空/有装备主菜单、四席小队的空席/自己/队友/准备及撤销/公开及私有/邀请码悬停。可用 W2-02、W2-10、W2-13 的双端操作做输入序列。
4. 在 DPR 1/2、窄桌面及真实触屏 UA 复测，补齐连接失败、邀请无效/满员/资格不足、账号各分支、模式切换、短/长及非 ASCII 昵称。另做固定输入、时钟、随机流的动画对照。本页实测四种桌面几何、iPhone UA 裁切、加载、连接、菜单、两人小队、公开/私有、准备和退队；第三方广告、外部账号、完整小队错误矩阵和动画全时序仍未达到像素级验收。

复采命令（从仓库根目录运行，需要已有 `wave/node_modules` 和 `build/wave/native/wave_host_fixture`）：

```sh
CHROMIUM_PATH=/path/to/chrome-headless-shell \
  node wave/docs/client-ui/tools/capture-lobby.mjs /tmp/wave-ui-lobby
```

`WAVE_ARCHIVE` 默认指向 `reports/wave/W0/wiki`，必须已有 `wave/web/resources-20221030.json` 列出的原始 HTML、字体 CSS 和 WOFF2；`WAVE_NATIVE` 可覆盖本地 fixture 构建目录。脚本校验 SHA-256，拦截第三方请求，WebSocket 只桥接至本机临时测试宿主。输出 PNG 及 JSON（矩阵、样式、Path2D、绘制顺序），不改原件。JSON 和 PNG 是相近帧，未同步粒子和光标相位；同帧像素差验收仍需固定时钟、随机流并同步采样。
