# 05 · 本地资料组件（`0x8000`）

`0x8000` 是**每个连接自己的**资料实体（句柄 8193），不是其他玩家的资料。它决定
镜头、缩放、控制句柄、等级、装备与库存显示。字段是变长的；下面给出空数组时的
基线布局和已确认的固定偏移。

## 1. 记录外形

```
handle = 8193 (LE32: 01 20 00 00)
flags  = 0xcc
mask   = 0x008000 (LE24: 00 80 00)
body   = 607 字节
```

- 最小可用 body：`01` + 606 × `00`。首字节是等级，`$140` 的默认值为 1；
  全零会把等级设为 0，虽然能解码但不可玩（A，W2）。
- mask 只置 `0x8000`，不要与 `0x100/0x400/0x200000` 等叠加；资料实体没有
  世界位置。

## 2. 基线布局（空数组）

| wire 偏移 | 类型 | 含义 | 客户端字段 |
| ---: | --- | --- | --- |
| 0 | u8 | 等级 | — |
| 283 | f32 | 镜头 Y | profile `+2264` |
| 314 | f32 | 缩放 | profile `+2316` |
| 323 | LE u32 | 本地控制句柄 | profile `+?` |
| 327 | f32 | 镜头 X | profile `+2376` |

- 镜头 X/Y 与直觉相反：**283 是 Y，327 是 X**。旧实现把两者对调，导致权威位置
  正确但镜头漂移（A，W2-11）。
- 控制句柄是 4 字节小端；重生后换新句柄，旧输入必须被拒绝（A）。
- `profile +2336` 尚未命名，不能当作第三个镜头坐标（C）。

> 偏移 283/327/314/323 只在“空库存数组”时成立。资料对象在 607 字节 payload
> 之前还有变长数组；库存/装备数量变化后，客户端结构体中的绝对偏移会移动，
> 必须按解析顺序而不是固定偏移读取。

## 3. 变长部分

资料体在固定头之后包含（按客户端读取顺序）：

1. 等级与经验；
2. 16 个装备槽的类型/稀有度；
3. 库存数组（类型 + 稀有度 + 数量）；
4. 商店/解锁状态；
5. 镜头与控制字段（位于尾部固定区）。

具体数组长度由前置 `vu` 计数决定；客户端按序解析后把指针写到资料对象的固定
字段，因此**不能**用“总长度 607”反推每个数组的长度。线上契约以最小形式
（等级 + 零数组）为准；带库存的变长形式只需按同样顺序写计数与元素，服务端
不需要理解客户端内部结构体的绝对偏移。

## 4. 消费点

| 字段 | 消费者 | 行为 |
| --- | --- | --- |
| 等级 | `$140`、`$939` | 初始等级、UI 显示 |
| 镜头 X/Y | `$991` | 每帧设置相机；`+2376` X、`+2264` Y |
| 缩放 | `$991` | `+2316` |
| 控制句柄 | `$939`、`$973` | 绑定本地输入与实体 |
| 装备槽 | `$126/$998` | 快捷栏、回充扇形 |
| 库存 | 商店/合成 UI | 数量与解锁 |

- `$991`（948126–971914）是每帧更新函数，读取资料并写相机。
- `$973`（914325–915130）用控制句柄把输入映射到实体。
- `$126/$998`（60293–65823 / 974283–975368）解析回充并绘制。

## 5. 与服务端投影的对应

`wave/server/wire/garden_projection.cpp` 发送：

```cpp
// Entity 8193 uses the full form with the local profile component.
{1, 32, 0, 0, 0xcc, 0, 0x80, 0}   // handle, flags, mask
1, 606 × 0                        // level 1 + 空数组
```

- 这 8 字节头 + 607 字节体与 `$601` 的读取一致（A）。
- 服务端不伪造库存/XP 进度；只保证镜头、缩放和控制句柄可解析（A）。
- 镜头坐标 = W1 权威位置 × 5（本地显示比例），不是历史服务器比例（A）。

## 6. 常见错误

| 现象 | 原因 |
| --- | --- |
| 镜头漂移/地图偏移 | X/Y 对调，或把 `+2336` 当镜头 |
| 移动反向/边界异常 | 缩放或控制句柄错误；或场地 `0x2000` 半径被写成 1 |
| 快捷栏空白 | 装备槽数量/顺序错误，或回充未按 u16/65535 |
| 等级显示 0 | 资料首字节为 0；必须写 1 |
| 资料解析越界 | 用固定 607 偏移读取变长数组 |

## 7. 未决问题

- 经验/等级进度的精确字段与量化方式；
- 商店解锁位图与库存数组的完整 schema；
- `profile +2336` 的语义；
- 资料体中是否存在相机平滑/震屏参数（可能与 S→C `40` 的三 f32 有关）。
