## 2. Ready、退出与重连

### 2.1 输入失效的确定复现

同一页面依次点击 Ready、左上角 Abandon，再点 Ready。可以单人复现，不依赖特定花瓣。
表现为菜单动画继续播放，但小队面板闪退、操作无效；刷新后却进入已经由服务端创建的对局。

关键区别是服务端已经开局，原生客户端还留在退出状态。原生 `$987` 在 Abandon 时设置全局退出标记
`4350150`。它不是资料实体字段，删除花朵、arena 或重新发送资料不会清除。
`$3309` 收到更大的 world epoch 时会销毁旧世界并经 `$587` 重新初始化，才会清除该标记。
仅有“控制花朵非零”的断言会漏掉这个故障。

修复位于 [GardenSession](../server/app/garden_session.cpp) 和
[Bootstrap](../server/wire/bootstrap.cpp)：

1. 连接从已有对局离开或切换到另一对局时，递增 world epoch，发送全量新世界。
2. 清空旧投影、待处理请求、可靠序号、ACK 和生命绑定；新世界启动身份请求复用原成员。
3. 保持当前 WebSocket 的外层编码状态连续。消费已在途的旧 epoch 帧，但不再执行其中的请求或 ACK。
4. epoch 按变长整数读写，覆盖 127 → 128 的边界；数据库命令键加入 epoch，避免新世界重新使用序号时撞到旧事务。
5. 已开局收到 `Ready(false)` 时清除该成员的准备位，保留对局，完成原生 UI 的准备确认。

### 2.2 刷新后的装备同步

原生客户端在启动时重发装备缓存，此时尚未确认当前生命。若缓存与服务端保存的完整装备完全相同，
只确认同步，不执行装备事务。真正修改装备、制作或换槽仍保留当前生命和存活状态校验。
因此刷新能恢复同一对局，同时不能用启动请求绕过装备修改条件。

### 2.3 房间容量

保留 32 房间上限。新建房间需要空间时，仅回收“已经结束且全员断线”的旧房间，清理成员残留房码和准备位。
仍在进行或有在线成员的房间继续保留。无法接受且没有所属房间的 Ready 使用现有显式断线恢复提示，避免一直等待。

## 3. Abandon 后的 arena 清理

主动离场和临时断线需要不同的模拟命令：

| 操作 | 模拟动作 | arena 与其他队员 |
| --- | --- | --- |
| 刷新/网络断开 | `Connection{player, false}` | 保留原身份与花朵以便重连；清除持续移动和攻击输入。 |
| Abandon/主动离队 | `Departure{player}` | 下一模拟步移除退出者的花朵、花瓣、弹体、召唤物等所属实体，并移除该对局玩家记录。 |
| 最后一人主动离场 | 删除房间 | 对局对象和该 arena 随房间销毁。 |

`Garden::leave` 释放退出者席位并排入 `Departure`；`Match::apply_commands` 复用生命清理逻辑，
随后移除玩家。该步后续若还有针对退出者的延迟输入、连接或装备命令，会安全跳过。
退出者的新 epoch 清除其客户端旧 arena、波次、小队和控制对象；留队者仍使用原 epoch、原对局、原生命。
留队者通过原有实体删除/淡出流程看到退出者消失。

测试既检查退出者页面，也检查留队者视角及服务端实体，避免只看到“菜单正常”就认为清理完成。

## 4. 死亡与复活

命令 21 单独解析为 `Continue`。对局仍在进行时，Continue 保留队员并等待下一波或 Yggdrasil；
对局已经结束才离场。arena 元数据的 bit 1 仅在 `Phase::ended` 时置位，让原生死亡 UI 能区分等待复活和 GAME OVER。

下一波复活和 Yggdrasil 的模拟规则已存在，本轮修复协议接线。下一波恢复满血；Yggdrasil 在当前波恢复半血，
产生新的生命代次，旧生命输入继续被拒绝。

## 5. 蜈蚣间隙、重叠与移动

单独把节距缩到绘制半径会造成另一种故障：接触解算仍按完整碰撞圆分离各节，
链约束又把它们拉回较短距离。两个约束逐 tick 互相抵消，表现为重叠、回弹和追击姿态异常。

最终处理：

- 普通、邪恶、沙漠蜈蚣的节距统一为相邻碰撞半径之和，与接触解算一致；相应绘制系数恢复为 1。
- 参考仓库旧版 `engine/src/sim/movement.cpp`、`engine/src/sim/spawn.cpp`：出生沿每节转角 `-π/10` 的弧线排列，身体只在离前驱过远时收紧，转弯时允许压缩。
- 保留边界钳制和已有跟随顺序。水蛭继续使用 0.75 倍节距形成连续身体。
- 本轮没有调整怪物的目标选择、攻击判定、伤害、速度、仇恨或断节规则。

相关代码：[mobs.cpp](../server/sim/mobs.cpp)、[local.js](../web/local.js)。
