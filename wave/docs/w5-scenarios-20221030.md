## 蚁穴

2022-07-13 的日志确认高稀有蚁穴里只有 Queen 可以高于 Rare；2022-08-18 已加入洞内计时，
但没有记载时长。原件内嵌日志也有对应条目。
[日志转录](https://raw.githubusercontent.com/AstRatJP/florr.io-files/main/i18n/en_US/changelog.txt)

截止前的 [Ant Hole oldid 2081](https://official-florrio.fandom.com/wiki/Ant_Hole?oldid=2081)
（2022-10-08）说明 Rare+ 通过接触进入，本体不能攻击，也不会在外面持续生成蚂蚁。
Baby、Worker、Soldier 固定 Rare，Queen 与洞同级。清完敌人或超时后入口消失，
把玩家、幸存怪物、花瓣和地面物体传出。后写的历史条目将圆形内部的结束时间明确为
2023-01-19；仅采用这个形状边界，不沿用现代蚁穴数值。
[历史说明](https://official-florrio.fandom.com/wiki/Ant_Hole#Trivia)

[Fire Ant Burrow oldid 2449](https://official-florrio.fandom.com/wiki/Fire_Ant_Burrow?oldid=2449)
（2022-10-28）记载 C/U 接近后释放 30 只 Fire Ant 并消失；Rare+ 可进入，内部为 50 只。
Epic 有 3 只、Legendary 有 2 只、Mythic 有 1 只与入口同级，其余 Rare。它不可攻击，
入洞出生位置随机。这里的具体数量只有社区记载，标记为重建。

[Digger oldid 2485](https://official-florrio.fandom.com/wiki/Digger?oldid=2485)
（2022-10-29）记载第一次有人进入 Rare+ 洞时有 2% 概率出现同级友方 Digger。
抽取时机是首次进入，不是全部守卫清完之后。W3 的低稀有清场代理也已移除，C/U 不抽取 Digger。该精确概率只有同期社区来源，标记为重建。

## 独立 PvP

2022-09-13 日志确认较高稀有度怪物（约 PvE 第 18 波）、排行榜、按被击败者分数掉 Basic、
地图随人数变化，以及 Magnet 不再增加 PvP 拾取范围。
[日志转录](https://raw.githubusercontent.com/AstRatJP/florr.io-files/main/i18n/en_US/changelog.txt)

[PvP oldid 2067](https://official-florrio.fandom.com/wiki/PvP?oldid=2067)
（2022-10-06）记载持续随机刷怪、无小队、掉落仅能由一位玩家拾取、独立灰色场地。
它的怪物说明写“9种”却逐项列了10种，本地采用逐项列表：Bee、Hornet、Baby Ant、
Worker Ant、Soldier Ant、Rock、Ladybug、Dark Ladybug、Beetle、Spider。
不采用 Ocean 怪物、蚁穴或现代 Hel 的入口与分级规则。

Basic 的精确分数边界没有任何已证实档位。旧表写约 100、约 1000，Epic 又写约 13000?
且标为需要证明，Legendary 没给数字。最低档写 None，不是 Common；Mythic 不掉。
本地为可测运行采用下表，全部精确阈值标为复刻：

| 被击败者分数        | Basic     |
| ------------------- | --------- |
| 少于 100            | 无        |
| 100 至少于 1000     | Unusual   |
| 1000 至少于 13000   | Rare      |
| 13000 至少于 100000 | Epic      |
| 100000 及以上       | Legendary |

100000 没有史料依据。每个边界均应测试紧邻下一个可表示值、等于及紧邻上一个可表示值；
不能用“阈值测试通过”宣称这些数字曾由原服务器采用。

地图函数采用 `300 + 40 * sqrt(max(0, n - 1))`，其中 `n` 是当前连线且存活的玩家数；
地图随人数改变有原日志依据，函数、计数口径及即时收缩均是复刻。
掉落由首位满足距离的玩家取得，Magnet 拾取倍率固定为 1；不限制其其他能力。
原客户端 `$977` 的 `cached_pvp_unlocked` 通过表槽 159 → `$3411` 读取档案等级，
要求等级大于 14；因此入口最低等级为 15，服务端同步验证。
[原件协议定位](protocol/10-w5-scenarios.md)

使用访客已提交的装备，PvP 对局分数及随机序列与 PvE 隔离；最高 PvE 通关波不受 PvP 影响。
持续刷怪每 2 秒尝试一次，主怪上限 24；两者都是复刻参数。
怪物/玩家击败分数增量、装备继承细节缺少直接史料，采用值应和代码、规则报告一同冻结。

机器规则中的 `acceptanceIds` 是交付用例关联，最终通过范围以 W5 原生测试与原客户端真实 socket
报告为准；本取证文档本身不构成浏览器验收结果。

## 2026-11-26 配色与结算补齐

按本次要求，四个主场背景与原客户端对应菜单一致；洞内采用对应蚁穴本体外圈色。
Garden、Desert、Ocean、PvP 分别为 `#1ea761`、`#decf7c`、`#5785ba`、`#4d5e56`；
普通蚁穴和火蚁穴为 `#b58500`、`#b52d00`。固定原件的 Canvas 实测与冻结配色见
[配色夹具](../data/wire/20221030/w5-backgrounds.json)，此处不再采用临时估计 RGB。

入口关闭单独结算原目录的 XP 和掉落；C/U 外放的无主野生守卫可获得 XP、图鉴和掉落，
玩家召唤物不能重复获得野生怪物收益。最后一只守卫死亡与传出发生在同一 tick 时仍结算一次，
地面卡片与进行中的拾取随区域返回。独立 PvP 的卡片在场地收缩时夹回合法位置。
同 tick 互杀先冻结所有败者分数，再分配分数和 Basic，避免实体顺序改变掉落档位。
传送更新控制代际并保留物理生命起始代际；旧物理生命的毒击杀不能归给重入后的新生命。
PvP 断线在小队管理器的默认 300 秒座位保留期内可恢复，分数和装备保留，
人数变化与地图大小以已连接且存活的玩家为准。
