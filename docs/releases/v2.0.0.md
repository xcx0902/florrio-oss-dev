# v2.0.0 — Native authoritative multiplayer

This release completes the M08 delivery boundary: the browser client, native
server and deployment package are built from one source identity, and online
play no longer contains a local WASM/Worker fallback.

## Highlights

- Native C++20/Boost.Asio authoritative server with one shared `World` per room,
  a fixed 50 ms tick, binary WebSocket v2, room admission, reconnect tokens,
  bounded per-connection queues, heartbeats, graceful drain and fixed-label
  metrics.
- Online-only `dist-multiplayer` and `tools/dev-multiplayer.mjs`. The online
  entry constructs only `NetworkTransport`; it never loads `server.wasm`,
  `server-worker.js`, `worker.js`, `local-worker.js` or the dev-only transport.
- Real dual-browser PVP acceptance, capacity/soak harness, native package and
  deployment smoke. The package includes paired server/client protocol and
  catalog hashes, systemd/nginx/Caddy examples and SHA-256 inventories.
- `test:multiplayer:all` records the M08 ledger:
  `reports/multiplayer/current-verification.json`.

## Deployment

Use `release/multiplayer/<version>-<source12>-<runId>/` with the included
`README.md`, `server/config/default.json`, service unit and reverse-proxy
examples. Sessions are memory-only: upgrades interrupt live sessions, and paired
client/server protocol hashes are required. Drain with `SIGTERM`; `/readyz`
returns 503 before exit.

Linux x86_64 packages are produced by
`.github/workflows/multiplayer-linux.yml`; macOS packages produced locally are
host packages and are not a substitute for the Linux artifact.
