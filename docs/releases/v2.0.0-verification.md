## 延迟与 PVP 实测

本次 16 组真实 TCP 字节流延迟 / 抖动矩阵全部通过（0/80/150/250 ms RTT ×
0/±20 ms 抖动 × 预测开关，128 次真实按键）：

- 预测开启时 DOM 事件到完成绘制的身体位移 p95 为 **30.9—45.1 ms**；
  关闭预测为 **165.5—331.7 ms**。
- 250 ms RTT、±20 ms 抖动下，停止输入后最慢 **619.8 ms** 收敛到最新权威轨迹，
  低于 1 秒验收上限；最终位置误差最大 **0.00105** world unit。
- 16 组实际 renderer CPU p95 最大 **2.3 ms**，低于原 8 ms 预算。
- 6 组持续移动（0/80/250 ms RTT，预测开关）共 999 个采样帧，身体 / 相机
  停顿与回拉均为 0；修复前预测开启时约 66% 帧间隔停顿。
- 250 ms RTT、±20 ms 抖动下，预测 on/off 两组都完成移动、攻击、防御、死亡、
  掉落、重生和两房隔离；胜者 Alice、败者 health=0、重生 LifeEpoch=2、
  房内人数=2。同一共享战斗的权威血量与掉落由双方按相同 serverTick 核对。
