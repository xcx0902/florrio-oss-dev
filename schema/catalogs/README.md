| `report.json` | — | counts, cross-check, validation |

Validation performed by the splitter:

- petal type ids are dense 0–38;
- entity type ids are dense 0–22;
- every spawn target exists;
- every drop petal type exists;
- string keys are unique;
- server and client catalogs agree on every name/description.

`tools/layout-probe.mjs` re-decodes the same tables from the original wasm and
must match `evidence.bytesHex` and every decoded field.

Regenerate the derived tables with:

```sh
node tools/derive-petal-combat.mjs
node tools/derive-drop-chances.mjs --verify
node tools/gen-contracts.mjs
```

`drop-chances.json` is a derived data file, not hand-authored. Its `--verify`
mode runs the original initializer and compares every finalized drop entry.
